# 术语交叉引用实现说明

> 记录 `@gl-xxx` 术语交叉引用的架构、执行管线、配置关系和故障排查。
>
> 用法规则见 `本书撰写规范.md` P2「交叉引用」小节。

---

## 1. 功能概述

正文中写 `@gl-acid`，渲染后生成：
- 链接文本显示术语名（如 `ACID`），而非 Quarto 默认的编号（如 `A.1`）
- href 指向术语表对应条目的跨页路径（如 `../appendices/appendix-a-glossary.html#gl-acid`）
- 悬浮预览（tippy tooltip）显示术语定义

---

## 2. 涉及文件

| 文件 | 职责 |
|------|------|
| `_extensions/glossary-xref/_extension.yml` | 扩展元数据，注册过滤器并指定执行时机 |
| `_extensions/glossary-xref/glossary-xref.lua` | 核心 Lua 过滤器：构建术语映射、替换链接文本、修正 href |
| `_quarto.yml` | 三处相关配置（见下文） |
| `src/appendices/appendix-a-glossary.qmd` | 术语表源文件，用 `:::{#gl-xxx}` 定义条目 |
| `工具/glossary-xref.lua` | 过滤器副本，与扩展目录内容同步 |

## 3. `_quarto.yml` 中的三处配置

### 3.1 `crossref.custom` — 注册 `gl` 类型

```yaml
crossref:
  custom:
    - kind: float
      key: gl
      reference-prefix: ""
      caption-prefix: ""
      space-before-numbering: false
      latex-env: glossary
```

- `key: gl`：使 Quarto 识别 `@gl-xxx` 语法，将其解析为交叉引用
- `reference-prefix: ""`：引用时不显示前缀（默认会显示如"图 1"）
- `latex-env: glossary`：PDF 构建需要的 LaTeX 环境名，缺少此字段会导致 PDF 渲染报错

### 3.2 `filters` — 引用扩展

```yaml
filters:
  - quarto
  - glossary-xref
```

- `quarto`：Quarto 内置过滤器（必须保留）
- `glossary-xref`：引用 `_extensions/glossary-xref/` 扩展

### 3.3 无额外 `include-after-body`

原方案曾用 JS 替换链接文本，已移除。当前方案纯 Lua 实现，无需额外 JS。

## 4. 执行管线

```
@gl-acid（源码）
  │
  ▼ ① Quarto crossref 引擎（Lua，pre-render 阶段）
  │    识别 @gl-acid 为 gl 类型
  │    生成 <a href="#gl-acid" class="quarto-xref">A.1</a>
  │    （此时 href 为同页锚点，文本为编号）
  │
  ▼ ② Quarto book-crossrefs.ts（post-render 阶段）
  │    修正 .quarto-unresolved-ref 和 #heading-id 的跨页路径
  │    但 .quarto-xref 且非 heading 的链接不被处理 ← 关键：gl 链接被跳过
  │
  ▼ ③ glossary-xref Lua 过滤器（post-render 阶段）
  │    a. 替换链接文本：A.1 → ACID（从术语映射表查找）
  │    b. 修正 href：#gl-acid → ../appendices/appendix-a-glossary.html#gl-acid
  │
  ▼ ④ 浏览器端 tippy.js（运行时）
       悬浮预览：fetch 术语表页面 → 提取 #gl-acid 元素 → 显示 tooltip
```

**步骤 ② 被跳过的根因**：Quarto 的 `book-crossrefs.ts` 只修正两类链接——`.quarto-unresolved-ref`（未解析引用）和 `#heading-id`（标题锚点）。`gl` 类型已被解析（有 `quarto-xref` 类），且不是标题，因此不在修正范围内。步骤 ③ 的 Lua 过滤器补上了这个缺口。

## 5. Lua 过滤器逻辑

### 5.1 术语映射构建

`build_glossary_map()` 读取术语表源文件，解析 `:::{#gl-xxx}` 容器，提取容器内第一行非空非定义列表内容作为术语名：

```
:::{#gl-acid}
ACID                    ← 术语名（glossary_map["gl-acid"] = "ACID"）
:   数据库事务的四个属性  ← 定义（不提取）
:::
```

文件路径使用多路径回退，适配不同渲染上下文的工作目录：

```lua
local paths = {
  "src/appendices/appendix-a-glossary.qmd",
  "../src/appendices/appendix-a-glossary.qmd",
  "../../src/appendices/appendix-a-glossary.qmd",
}
```

### 5.2 链接文本替换

`Link` 钩子匹配 `href` 以 `#gl-xxx` 结尾的链接，将 `link.content` 替换为术语名：

```lua
link.content = pandoc.Inlines({pandoc.Str(glossary_map[id])})
```

### 5.3 href 跨页路径修正

`glossary_href(id)` 根据当前输出文件的目录深度，计算到术语表的相对路径：

| 输出文件位置 | 相对路径 |
|-------------|---------|
| `_book/index.html` | `src/appendices/appendix-a-glossary.html#gl-xxx` |
| `_book/src/preface.html` | `appendices/appendix-a-glossary.html#gl-xxx` |
| `_book/src/partXX-*/NN-*.html` | `../appendices/appendix-a-glossary.html#gl-xxx` |

路径通过 `quarto.doc.output_file`（Quarto 提供的当前输出文件路径）计算。

## 6. 扩展配置

`_extension.yml`：

```yaml
title: Glossary Cross-references
author: local
version: 0.1.0
contributes:
  filters:
    - path: glossary-xref.lua
      at: post-render
```

- `at: post-render`：确保过滤器在 Quarto 交叉引用解析**之后**执行。若设为 `pre-render`，AST 中尚未生成 `quarto-xref` Link 元素，钩子无法匹配。

---

## 7. 术语表条目写法

术语表（`src/appendices/appendix-a-glossary.qmd`）中每个条目的格式：

```markdown
:::{#gl-acid}

ACID

:   数据库事务的四个属性：原子性、一致性、隔离性、持久性。
:::
```

- `:::{#gl-xxx}` — 容器开标签，`gl-` 前缀的 ID 是交叉引用的 key
- 术语名（如 `ACID`）— 独占一行，Lua 过滤器提取此行作为链接文本
- 定义（`:   ...`）— Quarto 定义列表语法，悬浮预览显示此内容
- `:::` — 容器闭标签

## 8. 故障排查

| 症状 | 原因 | 排查 |
|------|------|------|
| `@gl-xxx` 渲染为 `?@gl-xxx` | `_quarto.yml` 中 `crossref.custom` 未注册 `gl` 类型 | 检查 `crossref.custom` 是否有 `key: gl` |
| 链接文本显示编号（如 `A.1`）而非术语名 | Lua 过滤器未执行或映射表为空 | 检查 `filters` 列表是否有 `glossary-xref`；检查术语表文件路径是否可访问 |
| href 为 `#gl-acid`（同页锚点）而非跨页路径 | `glossary_href()` 未生效或 `quarto.doc.output_file` 不可用 | 检查 `_extension.yml` 的 `at` 是否为 `post-render` |
| 悬浮预览无内容 | href 指向的页面不存在或 `#gl-acid` 元素不在目标页面 | 检查渲染后 HTML 中 href 是否为有效跨页路径；检查术语表页面是否有对应 ID 的元素 |
| PDF 构建报错 `attempt to concatenate a nil value` | `crossref.custom` 缺少 `latex-env` 字段 | 添加 `latex-env: glossary` |
| 术语映射表为空（`map_size=0`） | 术语表文件路径在工作目录下不可访问 | 检查多路径回退列表是否覆盖当前工作目录 |
