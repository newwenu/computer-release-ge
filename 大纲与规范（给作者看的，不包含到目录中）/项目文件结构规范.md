# 《计算机系统通识》项目文件结构规范

> 本规范定义全书源文件、图片、配置等资源的组织方式。
>
> **适用范围**：本书使用 Quarto 构建系统，源文件为 `.qmd` 格式。

---

**关键流转规则**：
- 制图源文件 → `工具/制图草稿/NN/` → 导出 → `src/partXX/images/NN/`
- 工具最终成品 → `工具/output/` → 手动复制 → `src/assets/`

**关键说明**：
- 制图源文件（`.py`/`.html`/`.svg` 等）**只放** `工具/制图草稿/NN/`，**不放** `src/partXX/`；最终导出图片（PNG/SVG/HTML）才放 `src/partXX/images/NN/`
- 所有 `images/NN/`、`制图草稿/NN/` 目录均已初始化，写文件时直接写入

## 2. Part 目录结构

```
partXX-部分名称/
│
├── NN-章节名.qmd                           # 章节源文件（NN 为两位序号）
│   ...
│
└── images/                                 # 本 Part 所有图片
    ├── NN/                                 # 第 NN 章的图片子目录
    │   └── xxx.png                         # 图片文件
    └── ...
```

### 2.1 命名规则

| 元素 | 命名格式 | 示例 |
|------|---------|------|
| Part 目录 | `partXX-部分名称/` | `part01-信息与编码/` |
| 章节文件 | `NN-章节名.qmd` | `01-什么是信息.qmd` |
| 图片子目录 | `images/NN/` | `images/01/` |
| 图片文件 | 描述性英文名 | `abacus.png`, `cpu-diagram.svg` |

**关键约束**：
- Part 目录名使用**半角连字符** `-`
- 章节序号用**两位数字**（01–27）
- 图片子目录只用**序号**，不用章节名
- 图片文件名用**英文**，不用拼音或中文

### 2.2 图片引用路径

```markdown
![图：算盘示意图](images/01/abacus.png){#fig-abacus}
```

**禁止**：使用绝对路径或跨越多个 `../` 引用其他 Part 的图片。

## 3. 章节文件命名与编号

全书共 27 章，编号从 `01` 到 `27`，**连续无跳号、无重复**。

### 3.1 章节拆分

若某章内容过长或概念过多，需拆分为两章：

1. 后续所有章节序号顺延
2. 按新序号重命名 `.qmd` 文件
3. 同步更新 `_quarto.yml`、`@sec-` 引用、图片目录

**推荐命名**：赋予独立章节名，不用"（上）""（下）

## 4. 图片资源管理

### 4.1 图片分类与存放

| 图片类型 | 存放位置 | 格式 | 来源 |
|---------|---------|------|------|
| 概念示意图 | `images/NN/` | SVG/PNG | 自行绘制 |
| Mermaid 导出 | `images/NN/` | PNG | 自行生成 |
| 硬件照片 | `images/NN/` | PNG/JPG | 厂商公开或 CC 授权 |
| 界面截图 | `images/NN/` | PNG | 自行截图 |
| 交互式图表 | `images/NN/` | HTML | 自行绘制 |
| 行内图标 | `assets/icons/` 或 `images/NN/` | PNG | 自行绘制 |

### 4.2 Mermaid 图表

**方式一：内联**（简单图表，<10 节点）

```markdown
```mermaid
flowchart LR
    A[输入] --> B[处理]
    B --> C[输出]
```
```

**方式二：导出为图片**（复杂图表、需统一配色、多处引用）

### 4.3 交互式图表（HTML）

部分图表使用 HTML 格式实现交互效果（如时序图）：

- 源文件放 `工具/制图草稿/NN/`
- 成品放 `src/partXX/images/NN/`
- 在 `.qmd` 中通过 `<iframe>` 或 Quarto 的 HTML 嵌入语法引用

### 4.4 行内图标

- 文件名加 `icon-` 前缀
- 通用图标：`assets/icons/`；章节专属：`images/NN/`
- 尺寸统一 16–24 px
- **不编号**，不加 `{#fig-xxx}`，不加图注

### 4.5 图片版权标注

非自行绘制的图片，必须在图注中标注来源：

```markdown
![图：Intel Core i9 处理器](images/07/intel-core-i9.png){#fig-intel-cpu}

*图片来源：Intel 官方媒体资源*
```

## 5. 新增文件类型的处理

| 场景 | 处理方式 | 存放位置 |
|------|---------|---------|
| 新增附录 | 视为独立章节 | `src/appendices/` |
| 章节配套数据 | 与章节同目录或建 `data/` | `partXX/data/` |
| 大型表格 | 导出为 CSV | `partXX/data/` |
| 代码示例 | 如确需，放 `code/` | `partXX/code/` |
| 作者笔记/草稿 | 不提交主分支 | 个人分支或本地 |
| 截图脚本、批处理工具 | 放工具目录 | `工具（给作者用的，不参与构建）/` |
| 通用图标 | 放 assets | `src/assets/icons/` |

**新增目录前**：在作者群中讨论，更新本规范。
